# KataBox Arch 0.9.0-beta.1 (draft)

> Draft release notes. The version is still 0.1.0 in the code; the maintainer bumps it when cutting the beta
> (`.handoff/maintainer-steps.md`).

KataBox Arch is a free, offline desktop app for practising system design: build a design from real products, run a
deterministic traffic simulation that animates every request, and get graded against the problem's targets.

## Highlights
- **30 problems** in two sets, each with visible and hidden tests, three hints, an editorial and estimation drills.
  Set 2 adds image thumbnails, session stores, webhooks, feature flags, page-view counters, checkout, marketplace
  search, log pipelines, bulk email, collaborative docs, a payments ledger, surviving a region outage, file sync, an ad
  click aggregator and an order-matching exchange.
- **Practice beyond problems:** a numbers cheat sheet, estimation drills, ten "Find the flaw" drills, five learning
  paths, and quizzes on every Guide entry and pattern with spaced review of missed questions.
- **The simulator** models worker leases, change data capture, stream partitions, regions with local reads, network
  splits, provider rate cuts, p99 targets and unfinished work at the end of a run.
- **Problem packs:** import `.kbpack` files with a preview; every pack is checked (files, text, and a judged run of
  every design) before it installs.
- **Exports:** Mermaid (copy or save), SVG and PNG images.
- **Related in KataBox:** Guide entries, patterns and problems name the KataBox Learn topics and problems behind them.
- **Accessibility:** every page checked for landmarks and named controls, full names for cards and connections,
  announced run states, reduced motion that follows the system.

## Upgrading
- Designs saved by earlier versions open with calibrated defaults wherever a card still held an M0 placeholder (for
  example a Redis card at 0.5 ms now runs at 0.01 ms).
- `user.db` upgrades itself (to version 6) and keeps a backup of the old file first.

## Known issues
See [docs/known-issues.md](../docs/known-issues.md). Not in this beta: AI review (M4), GIF/WebM export, the
printable Guide, the in-app problem editor and docker-compose import.

## Privacy
No account, no network, no telemetry. The only network use will be AI review requests you start yourself (M4).
